# 엔티티와 값 객체 (Entity & Value Object)

## 엔티티 (Entity)

> [!note]
> **엔티티(Entity)**: 객체가 관련 속성 외에 자신을 식별할 수 있는 속성을 포함한 것

엔티티는 애플리케이션의 생명주기 동안 속성값이 변하더라도 식별값을 통해 연속성을 유지한다. 값과 값과 관련된 함수를 하나의 객체에 모아두면 응집도가 높아지게 되고 이를 통해 객체를 중심으로 영향 범위를 파악하고 대응할 수 있다.

## 값 객체 (Value Object)

> [!note]
> **값 객체(Value Object)**: 값과 그와 관련된 로직의 집합으로 엔티티와 달리 식별을 위한 속성을 갖지 않는다.

엔티티는 애플리케이션의 생명주기 동안 속성값이 변하더라도 식별값을 통해 연속성을 유지한다. 값과 값과 관련된 함수를 하나의 객체에 모아두면 응집도가 높아지게 되고 이를 통해 객체를 중심으로 영향 범위를 파악하고 대응할 수 있다.

값 객체는 애플리케이션 내에서 특별한 의미를 가진 값을 다룬다. 값 객체는 오직 그 자체 데이터인 값으로만 비교되고 다루어져야 한다. 이때, 값은 "불변성"을 가지는 것이 중요하다. 만약, 수시로 변경되어야 하는 값이 있다면 변경된 값을 가진 새로운 객체를 생성하여 기존의 객체를 대체해야 한다.
