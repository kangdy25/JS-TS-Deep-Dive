# 부수 효과 (Side Effect)

> [!note]
> **부수 효과(Side Effect)**: 어떤 동작을 했을 때 기대하는 결과 외에 외부의 상태를 변경하거나 관찰 가능한 다른 일이 벌어지는 것

프론트엔드 애플리케이션은 사용자와 상호작용하고 서버와 통신도 하기에 본질적으로 부수 효과를 다룰 수 밖에 없다. 그러나, 부수 효과는 코드를 이해하기 어렵게 하고 예상치 못한 결과를 낳기에 부수 효과를 잘 다루는 것은 매우 중요하다.

## 순수 함수와 투명 가능성

부수 효과가 없으며 동일한 인자에 대해 항상 동일한 값을 반환하는 함수를 **순수 함수**(Pure Function)이라고 한다,

어떤 표현식(a)을 그 표현식의 결괏값(b)으로 대체했을 때 전체 프로그램의 동작에 변화가 없다면 표현식 a를 참조 투명하다고 한다.

## 부수 효과의 성질

부수 효과는 외부에 영향을 주기에 호출하는 순서와 횟수에 따라 애플리케이션에 미치는 영향이 달라질 수 있다.

부수 효과는 전염성을 가지며, 이는 순수 함수(Pure Function)가 부수효과를 가진 비순수 함수(Impure Function)를 단 하나라도 호출하면, 그 함수 역시 즉시 비순수 함수로 오염된다는 것이다.

따라서 부수 효과를 가진 모듈은 응집도 있게 관리하고 높은 수준의 모듈에 둬서 부수 효과를 파악하기 쉽게 해야 한다.

## 부수 효과 분리

결국, 부수 효과를 다루는 방법은 부수 효과를 가진 모듈과 그렇지 않은 모듈을 분리하는 것이다.

> [!note]
> **FCIS(Functional Core, Imperative Shell)**: 시스템의 중심부에는 순수 함수로만 이루어진 Functional Core를 두고, 바깥쪽에는 부수 효과를 수행하고 조율하는 Imperative Shell을 배치하여 부수 효과의 전염성을 차단한다.

FCIS 패턴은 부수 효과가 가진 전염성을 이해하고 최소화한다.

## 웹 프레임워크와 부수 효과

React, Vue와 같은 웹 프레임워크에서는 주로 컴포넌트 외부에 있는 데이터 또는 상태와 상호작용하는 컴포넌트는 부수 효과를 가진다. 또한 부수 효과를 위해 정의한 이벤트 리스너나 이펙트를 갖는 컴포넌트도 부수 효과를 가진다.

외부 자원에 접근하는 로직은 변화에 대응할 때 매우 중요하지만 파악하기 어렵다. 그러나 모든 API 호출과 하위 컴포넌트가 공유하는 상태를 단일 컴포넌트에서 관리하면 코드 복잡도가 매우 높아지게 된다.

따라서 적정 수준에서 외부 자원에 접근할 수 있는 권한을 정의해야 한다.

## 부수 효과와 블록 컴포넌트

외부 자원에 접근할 수 있는 중간 수준 컴포넌트를 지정하려면 해당 컴포넌트에 특별한 의미가 있어야 하며 이때 BEM(Block Element Modifier)과 엘리먼트를 활용할 수 있다.

자체적인 의미를 갖는 요소 집합이라는 개념인 "블록"을 활용하면 외부와 내부의 경계를 명확히 구분할 수 있고, 이는 부수 효과로 인한 영향 범위의 기준으로 활용이 가능하다.

### BEM(Block Element Modifier)

BEM은 UI를 Block, Element, Modifier의 3가지 요소로 분해하여 표기하는 방법론이다.

- Block (블록): 그 자체로 독립적인 의미를 가지는 최상위 UI 컴포넌트 단위입니다. (어디에 가져다 놓아도 독립적으로 동작할 수 있는 독립 개체
  - 표기: .block
  - 예시: .header, .card, .button, .menu

- Element (엘리먼트): Block 내부에서만 의미를 가지며, Block의 기능을 완성하기 위해 종속된 하위 구성 요소입니다.
  - 표기: 언더스코어 2개(\_\_)로 Block과 연결
  - 예시: .card\_\_title, .card\_\_image, .menu\_\_item

- Modifier (모디파이어): Block이나 Element의 상태(State), 외형(Theme), 변형(Variant)을 나타내는 수식어입니다.
  - 표기: 하이픈 2개(--)로 대상과 연결
  - 예시: .button--primary, .button--disabled, .card\_\_title--highlighted
