# DRY (Don't Repeat Yourself)

> [!note]
> **DRY(Don't Repeat Yourself)**: 중복 코드를 작성하지 않도록 하는 원칙

## 중복 제거

코드 중복은 인지하지 못하거나, 알고 있다 하더라도 중복 제거의 필요성을 느끼지 못할 떄 주로 발생한다. 코드 중복은 발생하기 쉽지만 동시에 코드 복잡도를 높이는 주요 원인이 된다.

중복 코드를 하나의 모듈로 모아서 관리하며 중복을 제거하며 또한 관련 로직의 응집도를 높인다. 이러한 과정이 처음에는 더 복잡해지는 것처럼 느낄 수 있지만, 이 과정은 코드 간의 의존성을 명확히 정의하고 관리하기 쉽게 만든다.

## 프론트엔드에서 중복 사례

프론트엔드에서 주로 발생하는 코드 중복 사례는 다음과 같다.

1. 스타일 중복
2. HTML 요소 중복
3. 데이터 모델 중복

## 중복 제거 전략

코드 중복을 제거하는 것은 중요하지만 섣부른 중복 제거는 오히려 코드의 복잡성을 높일 수 있다. 미래는 예측할 수 없음을 전제하고 우발적인 중복을 제거했다고 판단한 후에 코드를 다시 분리하는 등의 조취를 취하는 것이 중요하다.
